# Repository writing rules

- Use the ASCII hyphen-minus (`-`) in prose and metadata.
- Do not use Unicode dash or hyphen characters, including en dashes, em dashes, nonbreaking hyphens, figure dashes, or minus signs.
- Before committing content, search changed text for Unicode dash code points U+2010 through U+2015 and U+2212, then replace any matches with `-` or rewrite the sentence.
